# Parth.OS — iPhone-inspired portfolio

A single-file, GitHub Pages-friendly redesign of `sapreparth.github.io`.

## Deploy

1. Keep your existing `display_avatar.jpeg` in the repository root.
2. Replace the repository's existing `index.html` with the new `index.html` in this folder.
3. Add `Parth_Sapre_Resume.pdf` to the repository root.
4. Commit and push to `main`. GitHub Pages will update automatically.

## Features

- iOS-style lock screen, status bar, Dynamic Island, widgets, app icons and dock
- Responsive full-screen app views for Experience, Projects, Stack, Impact, Education, Certifications and Contact
- Spotlight-like portfolio search with `Cmd/Ctrl + K`
- Deep links such as `/#experience`, `/#projects`, and `/#skills`
- No framework, package manager or build process required
- Uses system fonts and inline SVG icons; the only local assets are your avatar and resume PDF

## Content source

Portfolio content was rebuilt from the supplied August 2026 resume and adapted for recruiter-friendly interactive presentation.
